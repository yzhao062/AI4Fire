# Retrieval rule v2: the design record

The movement-conditioned analogue rule for the allocation task: brief (`BRIEF.md`), development set (`dev-items.jsonl`, 599 items from 520 incidents disjoint from the evaluation set, built by `build_dev.py`), harness (`dev_eval.py`), the three design families produced on 2026-09-16 (A recent-dynamics matching, B nearest-neighbour ranking, C stability-aware stratified draw; each `design-<letter>/report.md` states its family, every variant's development numbers, and the frozen choice), and the decision (`DECISION.md`, 2026-09-17: family B's `nn_pers_chg`, chosen by the brief's prespecified rule). `run_allocation.py --rule v2` implements the frozen rule; `check_v2_transfer.py` shows the runner's draws equal the harness's on all 300 evaluation items and that the v1 draws are unchanged. Pool caches and pickled models are not stored; each `run.py` rebuilds them.
